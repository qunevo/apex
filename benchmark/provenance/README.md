# Earlier publication inventory

The v1 and v2 manifest/validation pairs preserve earlier publication inventories.
Version 1 predates the directly accessible dataset; version 2 predates packaging
the measured algorithm in a ZIP. Each manifest describes its earlier layout,
including earlier documentation and helper hashes.
Use `../publication_manifest.json` and `../publication_validation.json` for the
current package. Original experiment manifests and result files are unchanged.
