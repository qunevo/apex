# Getting help

Start with the [README](readme.md), [documentation index](app/docs/README.md), [operating guide](app/docs/implementation.md) and [agent integration guide](app/docs/agent-integration.md).

- **Usage and design questions:** search or open a [Discussion](https://github.com/qunevo/apex/discussions).
- **Reproducible bugs and feature requests:** use the [issue forms](https://github.com/qunevo/apex/issues/new/choose).
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md) and report privately.
- **Licensing and commercial scope:** read [LICENSING.md](LICENSING.md) and the [pricing guide](app/docs/legal/pricing.md). Use the contact options on the [APEX website](https://apex.qunevo.com) for commercial inquiries; do not post private contract or company information in issues.

Provide the version or commit, platform, relevant command or tool call, and a minimal synthetic example. Do not attach customer exports, production plans, secrets or local runtime stores. Community support has no guaranteed response time. APEX remains experimental; passing tests is not a production-readiness guarantee.
