# Common UI

`index.html` is the existing viewer, embedded in the executable by the server.
It carries the selected customization in tool calls, links and copied agent
context. Rebuild the executable after edits.

This directory is also the future home of shared components and MCP Apps view
integration. The current server exposes MCP tools and HTTP, but does not yet
register MCP Apps UI resources. The browser viewer continues to work as before.
