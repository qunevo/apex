2. Edit the shared Excel workbook

The starter opens this file in your spreadsheet application. Edit it and save with Ctrl+S (or ⌘S on Mac). Both containers see the saved file.

{{workbook}}

If it did not open, paste this path into your spreadsheet application's Open dialog. A download from the MES is a separate copy. The MES table preview shows the original baseline, not your Excel edits.

To start over: close the workbook in Excel, then choose Reset demo in the MES. This restores both MES data and this working file. Reopen the workbook afterward; do not save an old open copy over the reset file.

3. Connect your local chat

Copy the setup instructions into a local agent that can configure its client and access files on this computer. It may ask you to reconnect the client to load the tools.

View setup instructions and connection details

Connect once and reuse the token. Container restarts and rebuilds keep it when the same data volumes are retained. Deleting those volumes or creating a separate installation generates new credentials.

APEX MCP currently provides planning tools. Reading the MES and Excel sources requires the local agent's HTTP and file tools; the factory import adapter is not implemented yet.
